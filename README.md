# Smart Contracts WeiFly

## 📦 Tokens y Licencias

### Tokenomics

- **AIRL**: Token principal (ERC-4337)
  - Total supply: 10M tokens
  - Distribución:
    - 40% Rewards Pool: 4M AIRL
    - 15% Tesorería: 1.5M AIRL
    - 15% Marketing: 1.5M AIRL
    - 10% Desarrollo: 1M AIRL
    - 20% Reserva: 2M AIRL

- **AIRG**: Token de staking (ERC-4337)
  - Ratio: 1 AIRL = 100 AIRG/día
  - Burns controlados
  - Inicialmente limitado para validar demanda

- **NFT Licencias**:
  - N1: C172 (Básico)
  - N2: C700 (Avanzado)
  - N3: B737 (Comercial)
  - N4: A320 (Professional)
